#  🔐 The Encoder - Программа для шифрования файлов

![Версия](https://img.shields.io/badge/Версия-2.3-blue)
![Python](https://img.shields.io/badge/Python-3.6+-green)
![Платформа](https://img.shields.io/badge/Платформа-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey)

Моя простенкая программа для шифрования и дешифрования файлов с графическим интерфейсом.

## 🌟 Особенности

### 🎯 Основные возможности:
- **3 метода шифрования:** AES-256, XOR, Base64
- **Графический интерфейс:** Интуитивно понятный интерфейс
- **Пакетная обработка:** Работа с файлами и папками
- **Кроссплатформенность:** Работает на Windows, Linux, macOS
- **Поддержка всех форматов:** Любые типы файлов

### 🛠 Дополнительные функции:
- 🔑 Генератор надежных паролей
- 💾 Создание резервных копий
- 🗑️ Опция удаления исходных файлов
- 📋 Подробный лог операций
- 🧪 Встроенная система тестирования
- 📊 Прогресс-бар с отображением выполнения
